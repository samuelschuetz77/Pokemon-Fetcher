# Pokemon-Fetcher
Framework: scaffold_then_guide. Student writes implementation one step at a time.
Source: https://snow.instructure.com/courses/1247151/assignments/19244922
Start with src/randomPokemonFetcher.ts (intentionally empty).
Use .ts for non-JSX logic/types and .tsx for JSX components.
Run npm run dev for development; npm run build and npm run lint for checks.
The scaffold intentionally renders nothing until the student implements the entry and components.

GitHub: https://github.com/samuelschuetz77/Pokemon-Fetcher (private). Registered as a Senior submodule.
